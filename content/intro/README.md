# Intro slideshow (D-111, D-112)

Nine stills for the opening slideshow, as real glyph cells (`*.ascii.json`: cols x rows, the game's `default` glyph ramp, per-slide palette, base64 fg/bg colour indices).

- **Source:** images generated by the owner with ChatGPT (OpenAI) from the prompts in `design/intro/prompts.md` (2026-10-15/16). The source images stay out of the public repo (`design/intro/src/`, git-ignored).
- **Converter:** `python tools/img2ascii.py --all` (Pillow) writes these files and git-ignored previews to `design/intro/preview/`.
- **Order:** 01-ferrum, 01b-before, 02-lamp, 03-light, 04-memory, 05-alive, 06-rope, 07-wall, 08-fall. Captions: `docs/story.md` "Opening sequence v2".
