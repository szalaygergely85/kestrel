ASCII QUEST - Windows build
===========================

HOW TO RUN
  1. Unzip the whole folder anywhere (not inside the zip viewer).
  2. Double-click "ASCII Quest.exe".
  No installer, no admin rights, no internet needed.

WINDOWS SMARTSCREEN
  The app is not code-signed, so Windows may show "Windows protected your PC".
  Click "More info", then "Run anyway". This only happens the first time.

REQUIREMENTS
  Windows 10 or 11 (64-bit) and a GPU with WebGPU support (any reasonably
  recent NVIDIA / AMD / Intel graphics with up-to-date drivers).

CONTROLS (defaults)
  Click in the window   capture the mouse (mouse = look around)
  W A S D               move
  Shift                 run
  Space                 jump
  E                     interact / read / talk
  Left mouse button     use left hand        Right mouse button   use right hand
  H                     swap hands
  Q                     lock on target       Tab   cycle target
  I                     inventory            M     map / chart
  J                     quest log            N     mute
  Esc                   pause / settings (graphics quality is in there)
  F11                   toggle full screen

SAVES
  Saves and settings live in your user profile:
    %APPDATA%\ASCII Quest
  Delete that folder to reset the game. The game folder itself stays unchanged,
  so you can move or delete it freely.
