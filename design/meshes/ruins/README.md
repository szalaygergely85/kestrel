# Ruins pack (CC0)

56 `.glb` models (Accessories, Blocks, Fences, Moss, Pillars, Skely, Stairs, Walls), public domain (CC0) - see
`THIRD_PARTY_NOTICES.md`. Committed as the real-asset input for the glTF importer (ME-13b:
`node tools/gltf-import.mjs design/meshes/ruins/<Group>/<Name>.glb <id>`). The pack's `.blend`/`.fbx` sources
(~77 MB) are not committed; they stay in git-ignored `design/meshes/source/RuinsGLB_CC0/`.
