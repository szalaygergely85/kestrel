Kestrel : treasure chests (S8-A-06, design v1.42) - model keys chestSmall, chestBig

design/models/chest.js: small 14 x 9 x 11 and big 22 x 15 x 18 voxels @ 0.05 m, parts glint / body / loot / lid (lid hinge on the back edge, rot x negative = open), clips closed (seam glow + hasp glint), open (0.6 s), opened (loot gone). Rendering = engine packVoxelModel / computeVoxelPose + the preview CPU march (lib/voxelMarch.js), v1 shader (palette.util.shade), approximate edge pass. The warm point light at mounts.light (chestFx.light) is simulated here (an engine light in game). Needs http: python -m http.server from the repo root, open /design/preview/chest.html.
