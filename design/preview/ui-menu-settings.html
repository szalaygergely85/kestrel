Kestrel : title menu, settings and pack screen styles (S8-A-04 / S8-A-05)

Data: design/models/menu_ui.js (uiStyle.menu, uiStyle.settings.controls / .quality / .full), design/models/inventory_ui.js (uiStyle.inventory + the appended slot.disabled / hands.disabled / states), icons from design/items.js, colours from design/palette.js (no palette change). Every screen is the fixed 160x60 UI layer (uiStyle.uiGrid) drawn over a stand-in scene; the scene grid toggle changes only the scene behind (dim + plate map to more cells), the UI cells are identical. Two display sizes: small 6x9 px per UI cell (960x540) and large 8x12 px (1280x720; the game is 12x18 at 1920x1080). Opens from file:// (no engine).

Checks

1. Title menu (uiStyle.menu) - New game / Continue / 3 slots / Delete / Settings

Click to focus. Arrows / W S select, Enter / Space choose, Del delete the selected slot, Esc back. Mouse hover selects, click chooses. Same rows and y values as the US-090a placeholder (game/js/ui/titleMenu.js): lane C only swaps colours / glyphs.

2. Settings panel (uiStyle.settings.full) with the Quality row

Click to focus. W/S select, A/D change (no wrap, disabled choices skipped: Ultra is marked "not available" in this mock), Enter toggles, Esc resets. Quality is a strip (every choice visible, current bracketed, Auto shows what it resolved to); Volume a slider; Mute / Reduce motion toggles; the rest selects.
