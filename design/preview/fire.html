Data: design/models/wreckage.js ASSETS.models.burnerFire (13x11 cells, half 7x6, 8 frames burn @ 12 fps, world 0.7 x 1.0 m, anchor bottom centre, every key emissive) and design/models/particles.js presets embers + smoke (the REAL engine sim, engine/fx/particles.js). The two scene views are crops at true pixel size on a 1920x1080 screen: 80x45 cells of a 240x90 grid (8x12 px cells) and 160x90 cells of a 480x180 grid (4x6 px cells) - the same patch of screen. Sprites use the engine rules (README section 4): projected rows = world.h * planeDistY / d, nearest sampling, lods.half below scale 0.75, upscale cap 3 * rows / 60. The burner can under the fire is the billboard burner without its own flame rows (for scale; the game draws the voxel burner). Particles in front of the sprite plane cover it, behind it are hidden (the engine's strict depth test). Needs http: python -m http.server.
