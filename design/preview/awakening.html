Kestrel : The Awakening - tower hall dressing (ENV-02, D-038)

Loads ../palette.js, ../detail-pass.js, the tower prop models and ../models/m3_props.js (the two composite sets awakeningCrates / awakeningKeeper, README 7.6), plus the real tower level (content/levels/tower.level.json through content-shim.js). Needs http (the shim fetches the JSON). The view is a reference raymarch, NOT the game renderer: level cells as height columns, the real voxel models of the burner, lamp, lever, canvas heap, gondola, strut, boulder and rubble (rest pose), the two composites, stand-in boxes for the pell and the sword, the level lights (burner torch, hook lamp) with the reference palette.util.shade and the morning sun (light-direction sliders). Emissive flames are drawn as glyph dots. "lit candle (option)" previews the canon call that is NOT in the level (the keeper's candle stub is cold: a lit one would say someone was here recently). Use it for composition, light pools and clearances; check the final look in the game (?renderer=mesh, then ?gpucompare=1).
