Kestrel : ART-REF-01 : the owner's two reference images, drawn in coloured letters

D-041 / D-042 item 3: ASCII stays; the art target is "the owner's two reference images drawn in coloured letters". Both panels are hand-composed mockups (procedural painter in this page, not the game renderer) that only use what our renderer can output per cell: one ASCII glyph + fg colour + bg colour. Glyphs come from the existing detail-pass.js sets where possible (grassFace / grassMid / turfMid / ivy / moss / rockFace / stoneFace / gap / brickFace / ironFace / strawFace / beam); four proposed sets are marked NEW. Shading uses the v2 rules (detailPass.shading: lift 0.12, gamma 0.70, fgMin 0.55, tint 0.60) with sun + ambient + point lights + haze. Palette mode "current" swaps every proposed colour for its nearest existing key and the light/haze values for today's presets, so you can see what the same composition looks like with today's data; "split" shows current | proposed side by side. Effects marked engine: not yet (sun rays, emissive bloom halo) are only drawn in proposed mode. Proposals only: palette.js and game data are unchanged. Works from file:// (classic scripts).

A. Stylized autumn meadow - warm afternoon (Quaternius Stylized Nature look)

B. Stylized fantasy house corner - low evening (Aurantia / Stylized Fantasy House Kit look)

Current palette keys that look too dull / brown next to the references

How to get there (proposals only - nothing is changed by this story)

  1. Palette additions (append-only, ids never move): the NEW keys in the two tables above (sky cyan, meadow, lime, moss rock, dirt, pebble, autumn yellow / orange / red, rust grass, birch, evening sun / ambient / bounce / haze, plaster, timber beam, slate, terracotta, lantern warm, window glow, petalViolet). Then remap the outdoor materials: materials.grass turf* -> meadow* (keep turf* for calm far ground), leaf* crowns -> lime* (near trees), new autumn crown materials for the birch species, rocks -> mossRock* with mossCap tint on up-facing texels, path ground type -> dirt*. Terracotta is needed because copper* is machine-only (style guide 2).
  2. Outdoor light presets data new timeOfDay.afternoon (sun sunAfternoon 1.15 @ elev 42, ambient ambientSky 0.40) and timeOfDay.evening (sun sunEvening 0.95 @ elev 12, ambient ambientEvening 0.30); light presets lanternHang (lanternWarm 0.9, r 3.0 m, flicker 6-10 Hz +-8 %) and windowGlow (windowGlow 0.35, r 1.2 m). Outdoor ambient 0.12 is the single biggest reason today's world looks dark and brown: shadows outdoors are lit by a bright sky.
  3. Hemisphere ambient + shadow tint small engine ambient = sky colour from above, ground-bounce colour from below (lerp by normal.z): sky blue 0.40 / grass green 0.12 by day, violet 0.30 / warm brown 0.10 in the evening. Optional shadowTint (shadowPurple, k 0.35) multiplied into sun-occluded fragments gives the reference's purple-brown evening shadows. Both are a few lines in the light accumulation (JS + GPU twins).
  4. Sky gradient + clouds data + small engine sky stops skyCyanTop / skyCyanMid / skyCyanHorizon (day) and skyEveTop / skyEveMid / skyEveHorizon (evening); skyHorizon must equal the far haze colour so hills melt into the sky. Clouds: a 2-octave fbm density in the sky pass (threshold 0.5, band 2-35 deg elevation), glyph from the existing sky ramp, bg carries the cloud body (lerp to cloudWhite by density), fg lit/shaded by comparing density above vs below (white tops, cool cloudShade undersides), plus thin streaks (fbm stretched 3x horizontally) for the wisps. Cloud shadows = the same noise scrolled on the ground, multiplied into the sun term (0.5 max).
  5. Haze small engine warm distance haze instead of cool fog: day near colour hazeWarm -> far colour skyCyanHorizon, start 15 m, full 700 m, curve 0.65, max 0.78 (new cap: far hills keep their shape and stay readable, never a flat wall); evening hazeEvening -> skyEveHorizon, 10 / 400 m, curve 0.7, max 0.6. fg goes to the haze colour, bg to haze x 0.9, glyph level drops 1 step per 0.14 haze above 0.45 (thinner far glyphs).
  6. Glyph sets data NEW crownClump (round clumps for crowns and bushes, shaded by a per-clump sphere normal blended 55/45 with the crown normal - the Quaternius clump look), bladeFace (foreground grass blades ' | / \ v that sway), dirtFace + pebble speckles o O . for the path, plasterFace (smooth, sparse) for half-timber panels; timber uses the existing oriented beam set. Flowers as single saturated specks * @ o . at every distance (dense flowers read as coloured dots far away).
  7. Houses: raking light relief engine has it posts 0.16 m, beams 0.13 m, braces 0.10 m and the stone base proud of the plaster: with D-043 sun shadow maps the low evening sun draws the long shadow strip right of every post and under every beam that makes reference B read. Modelling the depth is enough.
  8. Not yet in the engine new feature (nice-to-have, after the above): screen-space sun shafts (radial noise from the sun's screen position, added to bg); emissive bloom halo (bg += emissive colour x 0.42 x (1 - d/R)^2 around lanterns / windows, R 1.0 m). The mockup draws both only in proposed mode.
