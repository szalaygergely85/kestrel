Kestrel : particle presets (US-053c) : flame, smoke, sparks, dust

Data: design/models/particles.js - ASSETS.particles.presets (32.1 EmitterDef, colours as palette keys) + toEmitterDef(key, palette.rgb) (what main.js passes to engine.particles.defineEmitter). This page runs the real engine sim (engine/fx/particles.js, fixed 60 Hz steps, its own seeded RNG) and draws it with the 32.1 / 053b rules: 1 particle = 1 cell, stepped ramp index floor(age * n / life), emissive = ramp colour as is, non-emissive = ramp colour x the light at the emitter (sprite gain rule, fgMin floor, no cutoff - US-053c AC8). Side view, 1 cell = 5 cm wide x 10 cm tall (the 2:1 cell, so metres are square on screen). Back wall = the v1 stone shader under the same lights. Needs http: python -m http.server from the repo root, open /design/preview/particles.html.
