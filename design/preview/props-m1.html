Kestrel : M1 props set (S8-A-08, design v1.44) - design/models/props_m1.js

Waystone variants waystoneSmall / waystoneLeaning / waystoneFallen, lanternPost (clips lit / unlit), breachRubble, swordPedestal (shown with the real sword pickup in its slot). Rendering = engine packVoxelModel / computeVoxelPose + the preview CPU march (lib/voxelMarch.js), v1 shader (palette.util.shade), approximate edge pass, no shadows. Day = timeOfDay.morning, night = timeOfDay.night (moon); the lantern's point light (lanternHang at mounts.light) is simulated here (a level light in game). Needs http: python -m http.server from the repo root, open /design/preview/props-m1.html.
