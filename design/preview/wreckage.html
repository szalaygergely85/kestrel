Kestrel : the wreck of the Kestrel, the relay, and the new materials (D-011 reskin v1.9)

Loads ../palette.js, ../detail-pass.js, ../models/lantern.js, ../models/relay.js, ../models/wreckage.js. Look target (D-011): 80-90 % stone, wood, moss and ivy; brass and copper only on the machine (gondola, burner, lamp, relay mount); teal aether only on the relay. The crash room is a static stand-in drawn in 160x60 units and re-sampled for the scene grid (fixed canvas width, so finer grids = smaller cells, like the game). Surfaces use the v2 reference shader (DP.util.shade, the GPU path) or v1 (P.util.shade); sprites use util.shadeSprite. The light slider moves a directional light (colour from the preset) around the view: 0 = from the camera, +90 = from the right.
