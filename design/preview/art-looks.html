Kestrel : S8-A-10 : ART-02 .. ART-05 look sheets

One sheet per ART row (docs/epics/ep-alive.md ART-02..05, architecture.md 37.18). Every panel is a hand-composed coloured-letter mockup painted by this page (one ASCII glyph + fg + bg per cell, detail-pass v2 shading rules), not a capture of the game renderer. Before = today's data (palette keys, today's two fogs, today's GPU sky without clouds, today's glyph sets, flat house fronts). After = the same pose with only that sheet's change (tick "after = all four" to stack every sheet). Three poses per sheet: meadow, forest edge, house corner. The numbers are sliders; each sheet's copy values button emits the JSON a programmer / designer pastes (keys listed under each sheet and in design/README.md section 19). Proposals only: palette.js, detail-pass.js, levels and engine are unchanged. Works from file:// (classic scripts).
