Kestrel : quest marker (design v1.49, whole glyph glowing) - model keys questMark ('!'), questMarkReady ('?', quest ready to hand in, QG-D1)

design/models/quest_mark.js: 9 x 5 x 25 voxels @ 0.05 m (0.45 wide x 0.25 deep, glyph 0.90 m tall over a built-in 0.35 m float; anchor = the base point). One part mark (pivot = glyph centre), clips idle (spin 0.5 rev/s + bob 0.08 m, 2 s loop), bob (bob only, for an engine-driven spin), pop (0.3 s) and fade (0.25 s); the pop / fade scale comes from questMarkFx.popScale / fadeScale on the instance scale (clips have no scale key). The gold point light at mounts.light (questMarkFx.light) is simulated here. Rendering = engine packVoxelModel / computeVoxelPose + the preview CPU march (lib/voxelMarch.js), v1 shader, approximate edge pass. Needs http: python -m http.server from the repo root, open /design/preview/quest-mark.html.

Orbit + 4 fixed views ('!' left, '?' right; ground disc = the target the mark floats over)

Modes: the cycle is what the game plays for one quest step (pop 0.3 s, idle, fade 0.25 s, gap, next marker pops). "scrub: idle time" freezes the idle clip at the slider time (1000 ms = face-on, 0 / 2000 = back face, 500 / 1500 = edge-on; the bob peaks at 500 ms). "clip: bob + engine spin" = the alternative where the view drives the yaw. Sky "day" = a bright blue background to judge the read against the sky (v1.49: no dark rim any more; every voxel is brass_hot / brass_glint / ember_glow, all emissive).

In-game size (engine projection, 75 deg HFOV, 16:9, eye 1.6 m, grass, far fog): 3 m and 12 m day / night + the note mock

The mark sits at instance z 1.55 (= a note lying on the ground + placement.noteZOffsetM), so the glyph's bottom is 1.9 m up. The 3 m / 12 m views aim at the glyph centre (2.35 m); the note-mock views stand 7 m away and aim at 1.2 m so the page on the ground and the mark both show. Pose = the idle clip at the "idle time" slider (default 1000 ms = face-on). Night = sun 0.06, ambient 0.45, the mark light on.
