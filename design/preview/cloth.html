Kestrel : cloth look (CLOTH-1b4) : torn canvas, ruin banner, watch flag, linen curtain

Data: design/cloth.js (ASSETS.clothPresets silk / canvas / banner, numbers merged over the engine defaults; ASSETS.clothLooks = reference cloths blocks with pins + fray / tear holes), materials cloth.canvas, cloth.banner, cloth.flag, cloth.linen in palette.js (v1) + detail-pass.js (v2, glyph sets clothFace / bannerFace), colours woadLight / woad / woadDark. The sim is the real engine: createClothSystem (engine/world/cloths.js -> engine/physics/cloth.js), fixed 60 Hz ticks, markDrawn + sleep rules, the walker as body capsule 0. The raster is a preview stand-in for the rasterJS twin: perspective triangles, smooth area-weighted vertex normals (as updateClothMesh), two-sided (N flipped toward the eye), per-cell detailPass.util.shade with the cloth's rest-space uv, the kind-8 modelRim on silhouettes. No sun shadows here (the engine's sun map adds them). Needs http: python -m http.server from the repo root, open /design/preview/cloth.html.
