Kestrel : quest-giver NPC looks (Post-keeper + 10 region givers) + marker post / standing stone

NPCs: design/chargen/npc_looks.js = 11 CharRecipes on the EXISTING human kit base m_avg (content/chargen/human.charkit.json; no new body, existing ramps only, no palette edit) + 8 hats fitted to the kit's head (buildHats(kit)). Props: design/models/marker_props_voxel.js (markerPost, standingStone). Rendered with the real v1 surface shader (palette.util.shade, material ramps) by a small standalone voxel DDA; the composer is the preview twin chargenKit.composePreview (same rules as the engine composeCharacter, level-1 head). It ignores height / age (the engine stretches the shin / waist rows and makes elders one row shorter), so every NPC is shown at 1.75 m here. Light is fixed in the world (az 0 = from the front). Needs http for the kit JSON + the engine validator (python -m http.server from the repo root); from file:// it builds the kit with the generator and skips the engine validator.
