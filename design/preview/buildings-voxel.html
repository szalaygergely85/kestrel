Kestrel : our own buildings (OB-139, proposal - the owner picks before code)

Voxel buildings built by us instead of the kit-assembled Medieval Village houses (OB-138 / OB-129 / OB-147). Data: design/models/buildings_voxel.js (cellM 0.1 m, architecture.md 15.1 format + colliders + walk, see design/README.md). Left: the building turning (ASCII cells, glyph + colour from palette.materials, light from the sliders; colliders draws the box list as wire frames). Right: top-down plan of the chosen level with every collider box by kind, doors (cyan), NPC spots (white dots) and red cells = a pocket narrower than 0.9 m. Checks below: steps (rise <= 0.3, depth >= 0.3, width >= 1.2, headroom >= 2.0), doors (>= 1.0 x 2.1, nothing in the way), floating voxels (flood fill from the ground), collider support, materials. The renderer here is a light stand-alone splat preview (no engine imports); the engine format check runs only over http.
plan: north (front, y0) is UP; anchor = +; faint boxes = other levels
