Kestrel : the ruin-steel sword (US-078) : tower pickup + first-person view model

Data: design/models/sword.js - ASSETS.voxelModels.sword (world pickup, planted point-down in the rubble heap by the west wall, leaning, with a white "take me" glint sliding down the blade), ASSETS.voxelModels.swordHeld (the same voxels tip-up, pivot = grip), ASSETS.viewModels.sword (eye-space key poses: idle sway, swingLR = light (tap), charge + swingHard = hard (hold >= 0.4 s, release; D-034), chain rule (2 lights), trail + trailHard, sparks clink / hit / hitHeavy / chargeGlint; README 7.4) and ASSETS.levelPatch.towerSword (placement data). Old pitted steel, dark fuller, nicked edges, worn dark-leather grip, small down-curved bronze guard + pommel - no brass / copper / verdigris / aether. Materials are proposed (ASSETS.swordKit); this page injects their 3 new colours locally, the game does not see them until the merge step. Rendering uses the engine oracle (packVoxelModel, computeVoxelPose, marchVoxelRay from engine/voxel/) + the v1 reference shader (palette.util.shade) + an approximate edge pass, like voxel-props.html. The view model is drawn in its own depth range over a stand-in tower room. Needs http: python -m http.server from the repo root, open /design/preview/sword.html.

1. First-person view model (full screens, scene HFOV 75 deg, 16:9)

Left 160x60 (6x9 px cells), right 240x90 (4x6 px cells), the same screen area. Stand-in room: flagstone floor 1.6 m below the eye, stone wall 3.5 m ahead, ivy wall on the left. Lit by the light sliders (azimuth 0 = light from straight ahead, 90 = from the right) + ambient + the carried lamp, which hangs on the left once the sword is taken (x -0.3, down 0.3, forward 0.4; US-078 AC). The crosshair + is drawn at the centre. The trail (tip, newest = / / / \ / |, white -> mirror -> ironLight) only exists in the active window (80-200 ms), the ghost blade line : 50 ms behind. The hard swing uses trailHard (9 samples / 150 ms, body = / \ |, head # / %, white -> flameCore -> flameMid -> flameOuter -> emberDim, ghost %). Hit sparks are drawn at the crosshair (the target) in the middle of the active window: hit for a light, hitHeavy for a hard. chargeGlint pops at the tip when the charge is ready (400 ms). Segments after the first blend from the current pose (key 0 replaced).

1b. Tap vs hold, side by side (D-034; both press at the same moment)

Left = tap: press -> 100 ms of charge (the small pull-back) -> release before 0.4 s -> swingLR (light, 0.35 s, spark hit). Right = hold: press -> charge to the cocked pose (400 ms, chargeGlint at the tip = ready), held -> release at 1.1 s -> swingHard (0.63 s, trailHard, spark hitHeavy, long heavy recover). Use the speed selector to slow both down.

2. Key poses (every key of swingLR, charge, swingHard; 160x60, trail as it is at that time)

swingLR: k0 rest - k1 windup end (anticipation) - k2 / k3 / k4 active arc - k5 follow-through (overshoot) - k6 recovered (80 / 120 / 150 ms = 0.35 s). charge: rest - pull-back (100 ms, all a tap shows) - crossing - overshoot - held (400 ms). swingHard: charge pose - heave (67) - 4 active keys (67-183) - follow-through - hang - lift - recovered (633).
