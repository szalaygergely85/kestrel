Material response - MAT-RESPONSE-01 (designer preview, owner pick)

A small response table instead of full PBR: every material names one of five response types (matte, shiny, wet, metal, glowing). Each type has options A / B / C for how a lit surface answers: highlight glyphs and threshold, highlight colour (light colour vs material colour), rim / fresnel edge, wet darkening + sheen, glowing self-light. Same five scenes at noon, dusk and night (palette timeOfDay values). Rotate the light with the slider. The carried hand fire is on by default (the hand always burns), it is the main highlight source at night. Pick one option per type (two picks for matte and metal); picks are saved in this browser and shown in the Summary tab with a JSON export.
