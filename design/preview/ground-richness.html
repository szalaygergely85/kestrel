Kestrel : ENV-02-DESIGN : ground richness per biome

Proposal for the owner, nothing in the game changes. Each biome has 3 ground looks (A / B / C), drawn at the real cell grid (240 x 90 or 480 x 180, one canvas pixel block = one game cell, camera 1.7 m high looking along the ground). Each look = a glyph set (sparse to dense), a 4-tone colour ramp (blended smoothly, never hard bands), a patch size (noise scale, metres) and a wind shimmer amount. Decor-sized speckles (petals, pebbles, reeds) are shown as accents. They are candidates for the GPU decor pass (ENV-01).
No flicker by design (OB-054 / OB-067 / OB-073): patches are soft value noise in world metres, small octaves fade to their mean once a cell is too big to show them (far rows), every glyph is keyed by its world cell, and with wind = 0 the picture is byte-identical every frame (the "changed cells" counter under each panel stays 0). Wind moves a slow, coherent gust wave, not random cells.
Data: design/look/biomeLook.js (read by this page and by biome-atmos.html). Tick "pick" on a look and press "copy picks", or tell the main session the letters. Overlap: the far-grass region byte (P3-REGION-BYTE) and the carpet variants (38.52 item 2) should key off the same biome id.
