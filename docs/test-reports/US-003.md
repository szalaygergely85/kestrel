## Negative tests (one error at a time, deep-cloned in-memory copies of `test_room`'s def — repo files never touched)

| Case | console.error logged |
|---|---|
| Non-rectangular row (row 3 shortened by 1) | `row 3 has length 19, expected 20 (row 0's length) - grid must be rectangular.` |
| Unknown char (`?` placed at row 5, col 5) | `unknown legend character '?' at row 5, col 5.` |
| No start (removed `start:true` from `S`) | `no player start defined - set an explicit "start: {x, y, ...}"...` |

| Explicit `start` + a legend start marker both present | `both an explicit "start" and 1 legend start marker(s) are present; remove one. Legend marker(s) at: (row 2, col 2)` |
| `ceilMat: 'sky'` with numeric `ceilH` (set on `.`) | `legend '.': ceilMat is 'sky' but ceilH is not - ceilMat 'sky' is only valid when ceilH is 'sky'.` |
