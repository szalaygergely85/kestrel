## Performance

- `?bench=1` `present()`: avg 0.13 ms, p95 0.3 ms, max 1.5 ms.
- Live `test_room` play (small viewport, gl2 backend): fps fluctuated 15-38, `grid draw` (render call) 6.6-16.8 ms depending on view complexity — noisy, consistent with the "browser-automation sandbox" caveat both the US-001 and US-004 programmer notes already call out.
- Direct instrumentation of `castScene` in isolation (200 calls, `test_room`, default position, `skyFallback:true`, `depthBuffer` reused): **avg 10.64 ms, p50 10.10 ms, p95 12.40 ms, max 58.10 ms** (one clear GC/JIT outlier). This is higher than the programmer's own reported 6.5-7.3 ms, but in the same noisy sandbox family already flagged. This measurement **reinforces**, rather than newly raises, the PO's existing **ASK ARCHITECT #2 (frame budget)** item — flagging the number here for the architect's review, not as a new bug against this story (the acceptance criterion itself is a PO judgment call already made with this caveat on record).
