# PERF-01: voxel instances posed once per pass instead of twice (2026-10-16, PC-B, kestrel-1)

## Profile (before, ultra 480x180, CPU profile of the perf-pose spin, % of samples; same order at roadBend/forest/fordDetail)
computeVoxelPose 7.3 + matMul3 4.8-5.5 + buildRot 4.5-5.1 + setRz 3.4-4.0 + setRy 2.8-2.9 + samplePose 1.9 = **~25 % voxel pose**;
resetDrawItem (DrawList) 6.0-6.4; writeTexture 4.0-5.0; heightFn (world_geo) 3.6-4.8; addMeshStructures 2.5-4.6. GPU is 1-2.5 ms total, not the limit.
Cause: every queued voxel instance was posed (computeVoxelPose) 4x per frame: VoxelPool.project + addVoxelInstances (raster), projectShadow + addVoxelInstances (shadow list).

## Change
- `engine/render/voxelPool.js`: each projected/shadow slot keeps a copy of the FORWARD part transforms of the pose it was just given (`fwd`, `fwdModel`; fixed-size Float64Array per slot, zero per-frame allocation).
- `engine/mesh/voxelMesh.js` `addVoxelInstances`: uses the slot's `fwd` + `pose` (flags) when `fwdModel === model`; anything else (fixtures, plain objects) is posed as before. Same inputs and same code -> bit-identical matrices; 4 poses per instance per frame -> 2.

# PERF-02: foot IK skips the terrain normal + projectShadow reuses project()'s pose (2026-10-16, PC-B, kestrel-1)

## Profile (before, ultra 480x180, 2000 spinning frames, inclusive % of samples, roadBend / fordDetail)
footIkWire.step 10.6 / 7.4 (all in `groundAt` -> `supportAtOut` -> analytic `heightAt`: the kit NPCs stand OUTSIDE the near band (band x0 1024, feet at x ~910-922), ~7300 analytic heightAt/s, 4 of every 5 for a terrain normal the wire never reads);
point-shadow `_build` 10.8 / 10.9 (addMeshStructures 5.0, addVoxelInstances 4.3 -> push/resetDrawItem 2.9); projectShadow 4.1 / 4.4 (re-poses what project() posed); bakeAhead 17 / 22 (bake-ahead ring still filling after the 5.5 s settle: buildTrunkCollider's BVH build = 7-13 %, a one-call phase; transient, not touched); writeTexture 8 (present 5, particles 3).

## Change (bit-identical by construction)
- `engine/world/World.js` `supportAtOut`: `opts.heightOnly === true` skips `groundNormalAtBuf` (io[4..6] = 0 when terrain wins); `game/js/look/footIkWire.js` sets it (reads io[3] only). 5 analytic height evaluations per foot -> 1.
- `engine/voxel/instanceRect.js`: `instanceRect` = `computeVoxelPose` + new `rectFromForward(proj, pm, F, partAABB, rect)` (same arithmetic, F instead of FORWARD).
- `engine/render/voxelPool.js`: project() records raw slot -> projected slot (`_projSlotOf`, epoch-stamped; epoch moves on beginFrame/blend/leg/layerInstance); projectShadow copies pose + fwd of that slot when every pose input matches (`samePoseInputs`) and only computes the world AABB; anything else (screen-culled, JS path order, changed inputs) poses as before. Test: voxelPool.test.js PERF-02 (pose/fwd/AABB Object.is-identical to a fresh pose).
