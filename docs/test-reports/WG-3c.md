**Present decision (38.8).** The WebGPU path keeps PRESENTING the CPU cells (`rt.gpuActive` false, `frameComplete` false) until WG-3f. GPU cells go to the pipeline's own final textures and are read back only by the gate. Reason: the CPU compositor still owns sprites, particles, overlay, scene fade/dim, water and the sun-map shadow; presenting GPU cells now would drop them. Cost: shade+edge run every frame for nothing in the live game (experimental backend). The 400x150 shot (`docs/test-reports/captures/2026-10-08-WG-3c-roadSouth-webgpu-400x150.png`, git-ignored) shows the game unchanged (CPU cells; grid set via `engine.setGrid(400,150)` at runtime, `?grid=` is not honoured on webgpu).
