## Cause
CPU profile at roadBend: 38% in `sunVisibleP` (render/lighting.js), 15% `lightAtScratch`, via `sprites.project` (21 sprites x 48 DDA steps x 2 `world.structureAt` calls). `World.structureAt` scanned ALL `world.structures` (comment: "tiny") and skipped kind 'mesh' inside the loop; with ~370+ mesh structures that is ~1M iterations/frame. Instancing/draw list were fine (grouped rs plants are not capped, `addMeshStructures` ~0.9 ms/frame).

## Fix (smallest)
`World._gridStructures()` caches the non-mesh structures (keyed on array identity + length; localOverlay replaces the array); `structureAt` and the `worldMaxH` loop in `sunVisibleP` use it. No behaviour change.
