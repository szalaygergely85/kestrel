The builder plans a tracked runtime dependency closure before writing `dist/demo/` and a deterministic ZIP. It parses JavaScript with the project's existing TypeScript development dependency, follows literal imports/boot paths and content manifests, rejects missing files and unsafe paths, and refuses unverified asset licence groups. Notices and source hashes accompany the archive. The root itch.io launcher selects WebGPU and preserves other URL parameters.
