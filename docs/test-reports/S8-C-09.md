## Result

No actual charging/cutscene/capacity policy is invented in this view.

Locked slots use the designer's dotted border, darker interior and quiet x, drawn before live slots so shared borders retain the live style; selected slots still draw last. Locked items/counts are hidden; pointer and keyboard navigation skip locked slots. A selection that becomes locked displays the supplied Locked detail string and refuses item actions. All-locked navigation terminates without changing inventory. Busy hands keep their item icon, use the supplied bronze frame/dim label/(busy) tag, and flash refusal for assignment/clear. Moving an item out of a busy other hand also refuses. Unlock restores normal actions immediately.

Navigation retains the existing bounded grid and top-row-to-hand behavior tested by US-091b, rather than introducing the new checklist's wrap behavior: S8-C-09 is explicitly a DUP/gaps-only story in the validated queue.
