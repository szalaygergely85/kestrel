# PERF-MEASURE-02 desktop half / OCCL-ON (RTX 4060, headless WebGPU, 2026-10-15)

Summary:
1. RTX 4060 GPU total is 0.4-2.5 ms per frame at high and ultra; frame time is pinned at ~17.6 ms (headless vsync cap), so frame times carry no signal.
2. occl=1 does not save >= 0.3 ms anywhere (roadSouth ultra +0.56 ms, high +0.1; meadow ultra -0.24 but high +0.5; two high outliers at 4-6 ms are noise/hitches).
3. Result: `occl: false` in all five presets (no null left); nothing turned on. Laptop (Intel high/medium) rows are still open.
4. Preset `occl` is not consumed by main.js (only `?occl=1`), so the field is data until a one-line wiring is added.

Method: `bench-presets.mjs --quality Q --gpu rtx --imp off,on --seconds 10 --query occl=N`, one run per config. The tool reports only total GPU p50 (per-pass columns come back null) and frame p50/p95; no GPU p95, CPU time or draw counts are available from it. forestFloor/ultra/occl0/imp0 was skipped (not ready).
