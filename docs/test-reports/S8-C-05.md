# S8-C-05: controls binding data

The pure `game/js/quest/input/bindings.js` module supplies the current keyboard
defaults, copied from movement, hands, targeting, inventory and map callers.
Run retains both Shift keys; logical Mouse0/Mouse2 remain in the keyboard table
to match the existing Input codes. Debug shortcuts and modal navigation are
outside the gameplay action table.

Keyboard and gamepad are separate settings keys. Gamepad actions start unbound
because the current host has no shipped controller mapping; this module accepts
Button0..31 and signed Axis0..15 codes without choosing a controller layout.
This is data support only, not gamepad input sampling or live rebinding.

`createBindings(saved)` validates and copies version-1 snapshots. Missing actions
use defaults. `get` returns a reused immutable code list; `conflict` identifies
another action in the same device table. `rebind` refuses conflicts explicitly
without changing either action; null unbinds. `reset(device)` resets one table,
and `reset()` restores both. `serialize()` returns detached JSON-safe arrays for
the settings host to store. No storage, save-version, UI, engine or main edits.
