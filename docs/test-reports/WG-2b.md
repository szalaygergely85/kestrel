# WG-2b — mesh raster implementation in progress

2026-10-07, PC-B. This is a partial implementation awaiting PC-A decisions, not a completed geometry gate.

`wg/passRaster.js` uses shared DrawList/LevelMeshCache/MeshDrawCache/MeshBuffers and the same absolute projection/culling/feed order as the shipped GL pipeline. Static/kind-9 meshes, compact indexed voxel parts, instanced groups, and mirrored view-model voxel parts are submitted through GpuDevice only. Raster runs before debug in `_hook`, clears GI/GA to zero and SDepth to +Infinity each frame, and shares its depth attachment with a depth-only target for the view-model clear. CPU shading remains enabled (`frameComplete=false`, no `rt.gpuActive` takeover).

`wgsl/raster.wgsl.js` ports the shipped mesh vertex/fragment expressions: oct normals, AO wall/plane, packed metadata, smooth kind-9 normal and dominant-face threshold, perspective distance, clip-y/depth conversion, team remap, and cloth fragment normal flip. Static/voxel uniform blocks occupy 160 B; only instanced blocks include the team rows (304 B). All field offsets, typed views, and bind descriptors are cached. GpuDeviceWebGPU accepts optional `frontFace`, preserving default `cw`; mirrored voxel pipelines use opposite `ccw` with back-face culling.

Focused checks: `passRaster.test.js` verifies draw order/ranges, unsigned metadata, opposite mirrored winding, instance updates, the infinity sentinel, view-model depth-only clear, and zero new GPU resources across 1000 warm frames. `raster.wgsl.test.js` evaluates 1000 normal pack/unpack probes against the JS oracle and 1000 AO probes against the shipped GLSL expressions, plus shader/layout conventions. Existing WgCellPipeline and WGSL index suites pass; GpuDeviceWebGPU has 55 passing checks. check-deps OK (466 files, 1309 existing warnings before the new shader-probe suite).

Main-session real-GPU WGSL compilation: all six registered modules pass with zero errors/warnings (`present`, `debug`, `rasterStatic`, `rasterVoxel`, `rasterInstanced`, `rasterCloth`).
