**Files.** `game/js/saveRelay.js` (+`saveRelay.test.js`), `game/js/questRelay.js`, `game/js/platform/web.js` + `index.js` (`getSaveStorage`, the only localStorage access), `game/js/main.js` (relay create, 'world:loaded' hooks, boot load, fixed-step `stepGame`, HUD draw), `tools/save-reload-browser.mjs` (headless reload check).

**Flow.** Boot loads the fresh world, then if slot 0 holds a save `engine.setWorld(applySave(...).world)` (same swap as `R`). `saveRelay.onWorldLoaded()` runs first in the handler (consumes the pending restore or resets game data on restart); `applyDeadToBeasts` runs right after `createBeastSim` (dead beasts -> STATE_GONE). Autosave every 60 s of play (not while waking, dead, ending) and once on waystone touch (saved with `quest.endT=-1` so a load does not replay the end walk). `?save=0` off; capture/bench/gpucompare/cinematic pages and webdriver browsers never load/save unless `?save=1`.

**Quest.** Facts -> events each fixed step: wake done, `tower.lantern.taken`, `tower.sword.taken`, breach marker (3 m xy, 2.5 m z), `quest.endT>=0` = waystone; `beast:died` and `inventory:added` from the engine bus. `chest:opened {id}` is recorded for the save (no chest content yet). Objective text top-left of the UI layer (placeholder texts from m1.quest.json, writer pass pending).
