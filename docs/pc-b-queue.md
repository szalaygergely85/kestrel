### GROUND-SEAM-01 - tower outside ground + lower wall match the meadow / crown look (owner bug 2026-10-10)
(PC-B architect, owner-authorised while PC-A offline; PC-A to ratify. Engine rows end in arch-review (NEEDS PC-A).)

**Root cause (ground, confirmed):** the band is the tower LEVEL's outside cells (`,` 81 + `;` 32 + `l`/`k` 4, `floorMat: grass`, 2.4 m; content/levels/tower.level.json legend). `levelMesh.js` emits them as KIND_FLOOR quads shaded by the MaterialTable `grass` v2 entry (design/detail-pass.js:311, 1.4 m flat patches, no tufts), while the meadow is KIND_TERRAIN shaded by TLOOK (shade.wgsl.js:587). Terrain height there already equals the ring (structureBlend d=0 -> `ringHAt` = 2.4, overworld_far.js:346), so the terrain could be shown with zero height step.
**Root cause (wall, likely; verify with one capture):** lower walls are 1 m KIND_WALL quads with `stone*` v2 (detail-pass.js:224: grid 0.8 x 0.4, maxCover 0.25, tie). (2) shortcut, 0.5 d: levelMesh emits flagged cells as KIND_TERRAIN with the grass type id (same TLOOK look, no scatter, seam softer but tufts still stop). **Fix ranking (wall):** (1) rec, content 0.5 d: STONE far readability - `maxCover` 0.25 -> 0.5 (joints survive ~2x farther) and stronger block tone contrast in `stoneMid/stoneFar` + tones; (2) engine 0.5 d if (1) is not enough: add an x8 period step to the joint ladder (JS twin + WGSL, gpucompare gate); (3) voxel shell for exterior walls: NO (cost, collision duplication).
