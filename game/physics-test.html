US-008/US-009 physics test (test_room, top-down)

Playable top-down harness for the player capsule/gravity/collision/jump code (game/js/physics/, game/js/entities/Player.js) - independent of the game's real renderer/camera. Gold circle = grounded, blue = airborne; tick = facing. WASD move, Shift run, Space jump, Left/Right arrows turn, R reset to the level start. Click the canvas first so key presses aren't eaten by the page. HUD shows coyote/buffer countdowns, the current eye offset (step/dip/bob) and the last landing's fall distance.
